




Ｆ図の温度を計算するためにＦ図以外の残りの部分全体の温度は t 度で
見合い計算で t 目の後手ヨセがたくさん残っていると仮定します。
Ｆ図の温度は、双方が最善をつくすとき、
黒または白がＦ図で着手する可能性のある t の値に等しくなります。

t の値ごとに黒と白の最善手は以下のようになります。
以下、黒地はプラスで数え、白地はマイナスで数えることにします。

(1) t＞5 の場合

Ｆ図で黒も白も手抜きして他の場所でt目の後手ヨセを打つ。

黒先の場合
黒ツギ、白守り ⇒ -10
黒ツギ、白t目後手ヨセ、黒ツギ、白t目後手ヨセ ⇒ -2t (-2t < -10)
-2t < -10 なので黒ツギに白はt目後手ヨセとした方が得。
黒t目後手ヨセ、白受け ⇒ -13+t (-8 < -13+t)
-2t < -13+t なので黒はＦ図でt目後手ヨセとした方が得。

白先の場合
白t目後手ヨセ、黒ツギ、白守り、黒t目後手ヨセ ⇒ -10
白t目後手ヨセ、黒ツギ、白t目後手ヨセ、黒ツギ ⇒ -2t (-2t < -10)
-2t < -10 なので黒ツギに白はt目後手ヨセとした方が得。
白守り、黒t目後手ヨセ ⇒ -13+t (-8 < -13+t)
-13+t > -2t なので白はＦ図でt目後手ヨセとした方が得。

(2) 3＜t＜5 の場合

Ｆ図で黒が打てば先手になるが、
黒も白も手抜きして他の場所でt目の後手ヨセを打つ。

黒先の場合
黒ツギ、白守り ⇒ -10
黒ツギ、白t目後手ヨセ、黒ツギ、白t目後手ヨセ ⇒ -2t (-10 < -2t < -6)
-10 < -2t なので黒ツギに白は守った方が得。
黒t目後手ヨセ、白受け ⇒ -13+t (-10 < -13+t < -8)
-10 < -13+t なので黒はＦ図でt目後手ヨセとした方が得

白先の場合
白t目後手ヨセ、黒ツギ、白守り、黒t目後手ヨセ ⇒ -10
白t目後手ヨセ、黒ツギ、白t目後手ヨセ、黒ツギ ⇒ -2t (-10 < -2t < -6)
-10 < -2t なので黒ツギに白は守った方が得。
白守り、黒t目後手ヨセ ⇒ -13+t (-10 < -13+t < -8)
-10 < -13+t なので白はＦ図で白t目後手ヨセとした方が得。

(3) t＜3 の場合

Ｆ図で黒が打てば先手になる。
黒先ならば黒はＦ図でツギを打ち、白は必ず受けて次図になる。
_GOBAN_START_
●○○○○○○○○○　Ｇ図(外側の石は活石)
●◆●◇┼┼┼┼┼○　アゲハマ：黒石５
●○○○○○○○○○
_GOBAN_END_
白先ならば白はＦ図で逆ヨセを打ち(次図)、黒はt目の後手ヨセを打つ。
_GOBAN_START_
●○○○○○○○○○　Ｈ図(外側の石は活石)
●◇●┼●●●●●○
●○○○○○○○○○
_GOBAN_END_

黒先の場合
黒ツギ、白守り ⇒ -10
黒ツギ、白t目後手ヨセ、黒ツギ、白t目後手ヨセ ⇒ -2t (-6 < -2t)
-10 < -2t なので黒ツギに白は守った方が得。
黒t目後手ヨセ、白受け ⇒ -13+t (-13+t < -10)
-13+t < -10 なので黒はＦ図でツギとした方が得。

白先の場合
白t目後手ヨセ、黒ツギ、白守り、黒t目後手ヨセ ⇒ -10
白t目後手ヨセ、黒ツギ、白t目後手ヨセ、黒ツギ ⇒ -2t (-6 < -2t)
-10 < -2t なので黒ツギに白は守った方が得。
白守り、黒t目後手ヨセ ⇒ -13+t (-13+t < -10)
-13+t < -10 なので白はＦ図で守りを打った方が得。

以上の結果によって、黒も白も温度がＥ図以外の残りの部分全体の
温度 t が３度以下にならないとＥ図に打たないことがわかります。
したがってＥ図の温度は３度だということになります。
